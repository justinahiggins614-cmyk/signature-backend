● HOW THE MODES USE IT

  • The Creation Lab — labCatalogs() lists the eight mix-and-match shelfes; labOptions(key) returns every option on a shelf; animateCreation({base, picks}) forges the creation record (JAH-LAB-######, deterministic); labDemo(creation) runs its field test; creationToAI(creation) makes it dialable.
  • One-tap archetypes — presets() lists the 6 archetypes (one model of each kind); loadPreset(name) returns the full directory-grade record, ready to dial. Older preset names still resolve to their archetype.
  • Dial-up calls — dial(aiRecord) opens a live session: the AI answers with its greeting, say(text) chats with call-duration memory, runDemo(inputs) runs its demo, hangup() closes the line. session.lockRole('semiconductor replacement') locks the AI into a role for the whole call — replies turn concise, in-role, machine-friendly (short structured ROLE / ACK / OUT / END lines), suitable for driving automation; session.unlockRole() releases it back to normal conversation.
  • The Opperater — geneOptions(advanced) lists the gene boxes; genomeViable(drops) announces when the mix is a valid interactable AI; buildGenome({drops, attitude, name, tone, mission}) forges the record; fileRecord(rec) files a new AI into the book with a JAH-AI-OP-###### stamp plus .py and .json downloads.

⚗ The Creation Lab — the 8 shelfes

  • Step 1: pick a base archetype (or a blank slab) from the dropdown.
  • Step 2: open the 8 shelfes — Gene Splices, Body Parts, Brains, Power Sources, Lab Equipment, Serums & Elixirs, Habitats, Experiment Protocols — and tick the chips you want.
  • Step 3: press ⚡ ANIMATE! The same picks always animate the same creation — it arrives stamped JAH-LAB-######. 🎲 Surprise me ticks random chips; Clear picks starts over.

Your animated creation

  • 🔊 Read aloud reads it; 🧪 Run field test runs a scripted simulation (badged SIMULATION — not a real measurement); 📞 Dial this creation lets you chat with it; ⤓ .json / ⤓ .py download it.
  • The RECORD row: OPEN re-runs the saved spec, SOURCE shows provenance, # ID copies the stamp, VERSION shows the engine version, SHARE copies a ?creation= link that re-opens the exact same creation.
  • Serums & elixirs are speculative fictional concepts — not medical advice, not clinically validated, not real treatments or organisms.

● Engine API — talk to the AIs

  • Choose an AI: the 6 directory AIs, plus any creation you animated this visit. The identity card names it, lists its duties, and names the on-device engine that talks.
  • Send chats one line at a time. 📞 Dial opens a live call with memory for the whole call; press again to hang up.
  • 🔒 Lock role pins the AI into a job (type the role first, e.g. semiconductor replacement) for short automation-style replies; 🔓 Unlock releases it.
  • ⤓ Transcript downloads the whole call as JSON. Run working demo runs that AI’s own working demo.

● The Opperater — the genome forge

  • TEN main gene boxes (+ advanced): drop genes, slide the Warmth/Humor/Seriousness/Boldness knobs, name it and give it a mission, then forge. This is a separate forge from the lab’s 8 shelfes above.
  • ⚙ Forge a sample genome AI & dial it cooks a sample, files it with a JAH-AI-OP-###### stamp, downloads its .py, and dials it immediately.
  • ⤓ Export last forged genome (.json) downloads the genome file. Import AI JSON loads your own AI file — it is validated first, and bad files are rejected with a plain message.
  • Gene, serum & elixir play is speculative fiction — concepts only, not medical advice.

● Engine API tests

  • Five buttons run the real engine functions — chat(), dial(), runDemo(), geneOptions(), fileRecord() — on this device and report an honest PASS or FAIL. The ⚙ Lab Engine section at the bottom of the page shows the same results at boot.

🔒 Privacy

  • Every model’s content is pre-built into the page — the whole lab works offline with no network calls. Downloads go straight to your device; fileRecord() hands the stamped record back to you and saves nothing anywhere.
